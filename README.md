# OnmyojiAssist

一个基于 PyQt5 的《阴阳师》游戏自动化辅助工具，支持御魂周回与结界卡合成等功能。通过 OpenCV 图像识别与 Win32 API 实现多窗口并发自动化，可设置任务计数与完成后自动退出游戏/关机。

## 功能特性
- **多任务支持**：御魂（单人/组队）与结界卡合成自动化。
- **多窗口并发**：同时驱动多个游戏窗口，利用线程实现并行执行。
- **灵活配置**：支持任务计数、通关后停止、完成后退出游戏/关机等策略。
- **智能识别**：基于 OpenCV 模板匹配自动识别界面元素，适配游戏界面状态。
- **日志与监控**：实时输出执行日志，支持切换详细/精简日志等级。

## 快速开始

### 系统要求
- **操作系统**：Windows 10/11
- **Python 版本**：Python 3.7.x（推荐）
  - 注意：由于代码使用了 `time.clock()`，目前与 Python 3.8+ 不兼容，后续版本将修复此问题。
- **游戏客户端**：已安装《阴阳师》PC 版，且游戏窗口标题为"阴阳师-网易游戏"。

### 安装依赖

1. **克隆或下载仓库**：
   ```bash
   git clone <仓库地址>
   cd OnmyojiAssist
   ```

2. **创建虚拟环境（推荐）**：
   ```bash
   python -m venv .venv
   .\.venv\Scripts\activate  # Windows PowerShell/cmd
   ```

3. **安装依赖包**：
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

### 运行应用

1. **启动游戏**：
   - 打开《阴阳师》客户端，登录账号并进入主界面。
   - 将游戏窗口调整为窗口化模式（非全屏），确保标题栏显示为"阴阳师-网易游戏"。

2. **启动工具**：
   ```bash
   python main.py
   ```

3. **配置任务**：
   - 在弹出的 GUI 界面中选择任务类型（御魂/结界卡合成）。
   - 勾选"计数"并设置目标次数（不勾选则无限循环）。
   - 可选择"完成后关闭痒痒鼠"或"完成后关机"。

4. **开始执行**：
   - 点击"开始"按钮，工具将自动检测游戏窗口并启动自动化流程。
   - 在文本框中实时查看日志输出，如需停止可点击"立即停止"或"通关后停止"。

### 打包成可执行文件

如果希望在没有 Python 环境的电脑上运行，可使用 PyInstaller 打包：

1. **安装 PyInstaller**：
   ```bash
   pip install pyinstaller
   ```

2. **执行打包脚本**：
   ```bash
   python pyinstaller.py
   ```

3. **获取可执行文件**：
   - 打包完成后，在 `dist/` 目录下生成名为"阴阳师自动.exe"的可执行文件。
   - 将 `img/` 文件夹与可执行文件放在同一目录下，即可分发使用。

## 开发指南

### 项目结构
- **`main.py`**：应用入口，负责启动 Qt 事件循环与主窗口。
- **`OnmyojiAssist.py`**：主界面逻辑，管理 UI 交互与线程生命周期。
- **`OnmyojiThread.py`**：核心业务线程，实现御魂与结界卡合成的自动化流程。
- **`game_window.py`**：窗口管理与图像识别，封装 Win32 API 与 OpenCV 调用。
- **`game_control.py`**：输入控制，模拟鼠标点击事件。
- **`game_helper.py`**：共享辅助工具，包括日志配置、系统唤醒、倒计时消息框等。
- **`ui_onmyoji_assist.ui` / `.py`**：Qt Designer 生成的界面文件，请勿手动修改 `.py` 版本。
- **`img/`**：模板图片资源，用于界面元素识别。

详细模块职责与设计说明请参考：[**docs/CODEBASE_SUMMARY.md**](docs/CODEBASE_SUMMARY.md)

### 本地开发环境配置

1. **安装 Qt Designer**（可选）：
   - 用于编辑 UI 界面文件 `ui_onmyoji_assist.ui`。
   - 安装后可通过 `designer` 命令启动。
   - 修改 UI 后，使用以下命令重新生成 Python 代码：
     ```bash
     pyuic5 ui_onmyoji_assist.ui -o ui_onmyoji_assist.py
     ```

2. **调试技巧**：
   - 在 GUI 中点击"当前日志等级：精简"按钮，切换为详细日志模式。
   - 修改 `game_helper.py` 中的日志级别，将 `logger.setLevel(logging.DEBUG)` 用于更细致的调试信息。
   - 在 `main.py` 中取消注释测试代码，可单独运行窗口枚举与图像识别功能。

3. **模板图片更新**：
   - 如果游戏 UI 更新导致识别失败，可使用 `game_window.screen_shot()` 截取新的界面元素并保存到 `img/` 目录。
   - 图片文件名需与代码中的路径引用一致。

### 常见问题（FAQ）

**Q：启动后提示"未检测到运行中的阴阳师游戏窗口"怎么办？**
A：请确认游戏窗口标题为"阴阳师-网易游戏"，且游戏在启动状态。如果使用的是其他版本客户端，可在 `game_window.py` 第 21 行修改标题匹配逻辑。

**Q：识别失败或点击位置偏移？**
A：检查游戏分辨率是否为 1152×679。工具会在检测窗口时自动调整尺寸，但如果全屏或分辨率异常，可能影响识别精度。

**Q：如何支持 Python 3.8+？**
A：当前代码使用了 `time.clock()`（已在 Python 3.8 废弃），需将其替换为 `time.perf_counter()` 或 `time.monotonic()`。详细修复方法见 [TODO.md](TODO.md)。

**Q：如何调整识别灵敏度？**
A：在 `OnmyojiThread.py` 中，模板匹配的阈值为 0.9（如 `max_val > 0.9`），可根据需要调整该数值。较低的阈值会提高识别率，但可能增加误识别。

**Q：是否支持 macOS 或 Linux？**
A：不支持。本工具依赖 pywin32 与 Windows API，仅能在 Windows 平台运行。
