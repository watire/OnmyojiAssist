## 1. 阴阳师每日任务分析

### 1.1 每日任务清单

根据阴阳师游戏的常见每日任务，主要包括以下类型：

#### A. 核心战斗类任务（高频、高价值）
1. **御魂副本**（当前已支持）
   - 任务要求：刷取御魂副本若干次
   - 体力消耗：6 体力/次
   - 自动化难度：★☆☆☆☆（已实现）

2. **觉醒副本**
   - 任务要求：完成觉醒副本 3 次
   - 体力消耗：10 体力/次
   - 自动化难度：★★☆☆☆（与御魂类似）

3. **御灵副本**
   - 任务要求：完成御灵副本 3 次
   - 体力消耗：6 体力/次
   - 自动化难度：★★☆☆☆（与御魂类似）

4. **探索副本（章节关卡）**
   - 任务要求：通关普通/困难章节关卡若干次
   - 体力消耗：3-6 体力/次
   - 自动化难度：★★☆☆☆（与御魂类似）

#### B. 战斗类变种任务
5. **结界突破**
   - 任务要求：进行结界突破 3 次（攻击或防守）
   - 无体力消耗，但每日次数有限
   - 自动化难度：★★★☆☆（需识别对手选择界面）

6. **道馆切磋**
   - 任务要求：完成道馆切磋 3 次
   - 无体力消耗
   - 自动化难度：★★★☆☆（类似结界突破）

7. **百鬼夜行**
   - 任务要求：参与百鬼夜行（投豆子）
   - 时间限制：每日特定时段
   - 自动化难度：★★★★☆（需时间调度与豆子投掷识别）

#### C. 非战斗类任务
8. **寮突破**（当前已支持部分）
   - 任务要求：使用结界卡攻击阴界之门或破碎之门
   - 结界卡消耗
   - 自动化难度：★★☆☆☆（结界卡合成已实现）

9. **签到与领取奖励**
   - 任务要求：每日签到、领取邮件、寮福利等
   - 自动化难度：★★☆☆☆（界面导航 + 点击）

10. **召唤（抽卡）**
    - 任务要求：进行召唤（现世/神秘）
    - 消耗：勾玉/召唤券
    - 自动化难度：★★☆☆☆（仅适合使用免费券）

11. **妖怪屋收取**
    - 任务要求：收取妖怪屋产出
    - 自动化难度：★★★☆☆（需定位多个式神图标）

#### D. 社交类任务
12. **好友协战**
    - 任务要求：帮助好友完成协战副本 3 次
    - 自动化难度：★★★☆☆（需进入好友列表与副本导航）

13. **寮祈愿/寮捐献**
    - 任务要求：完成寮内社交互动
    - 自动化难度：★★☆☆☆

### 5.2 核心类设计

#### 5.2.1 任务抽象基类
```python
# tasks/base_task.py
from abc import ABC, abstractmethod

class BaseTask(ABC):
    """所有自动化任务的抽象基类"""
    
    def __init__(self, hwnd, lock, config):
        self.hwnd = hwnd
        self.lock = lock
        self.config = config
        self.stopped = False
        
    @abstractmethod
    def run(self, count=1):
        """执行任务主循环"""
        pass
        
    @abstractmethod
    def can_execute(self):
        """检查任务是否可执行（如体力是否充足）"""
        pass
        
    def stop(self):
        """停止任务"""
        self.stopped = True
```

#### 5.2.3 副本任务基类
```python
# tasks/dungeon_task.py
from tasks.base_task import BaseTask

class DungeonTask(BaseTask):
    """副本类任务基类（御魂、觉醒、御灵等）"""
    
    def run(self, count=1):
        """执行副本循环"""
        for i in range(count):
            if self.stopped:
                break
                
            logger.info(f"开始第 {i+1}/{count} 次副本")
            
            # 1. 导航到副本入口
            self.navigate_to_dungeon()
            
            # 2. 开始战斗
            self.start_battle()
            
            # 3. 等待战斗结束
            self.wait_battle_end()
            
            # 4. 领取奖励
            self.collect_reward()
            
            # 5. 检查体力
            if not self.check_stamina():
                logger.warning("体力不足，停止任务")
                break
                
    @abstractmethod
    def navigate_to_dungeon(self):
        """导航到具体副本（子类实现）"""
        pass
```
